Embuary Kodi Add-on Repository

This site hosts a Kodi repository feed for the Embuary (Omega) skin and its companion add-ons, plus a direct-install copy of the skin.

The skin is a fork based on Sualfred's original Embuary work, with Kodi Omega modifications by cybergrimes. The skin's original CC-BY-NC-ND-4.0 license is unchanged.

Repository feed: addons.xml (md5)

Install the repository ZIP: repository.embuary-1.0.0.zip.

Install the skin directly: skin.embuary-omega-21.0.1.zip.

Packages in the feed: Embuary (Omega) 21.0.1, Embuary Helper 2.0.9 and Embuary Info 2.0.9.

In Kodi, install the repository ZIP from file. The skin, Helper and Info are then installed and updated from the repository (Add-ons > Install from repository). Installing the skin ZIP directly also works.

Source and release steps: github.com/cybergrimes/skin.embuary.
