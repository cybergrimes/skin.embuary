Embuary (Omega) Kodi repository

Fork of the Embuary skin by Sualfred, adapted for Kodi 21 Omega by Cybergrimes. CC-BY-NC-ND-4.0.

Install

  1. Download the skin: skin.embuary-omega-21.0.1.zip.
  2. Download the repository add-on: repository.cybergrimes.embuary-1.0.0.zip and install it in Kodi (Add-ons > Install from zip file).
  3. Install the skin ZIP from file. Kodi pulls script.embuary.helper and script.embuary.info 2.0.9 from this repository.
